# Маски полей ввода: документы и госномер

Прототип и логика масок для полей российских документов и госномера автомобиля. Чистый JavaScript, без зависимостей.

- `index.html` — прототип полей документов (выбор типа документа, маска, ошибки, кнопка «Отправить»)
- `plate.html` — прототип поля госномера (РФ + иностранные номера)
- `doc-masks.js` — логика масок и валидации документов
- `plate.js` — логика маски госномера

Открыть прототип: скачать папку и открыть `index.html` в браузере, или включить GitHub Pages для репозитория.

Нули в шаблоне — только там, где вводятся цифры. Где можно и буквы, и цифры — пишем длину. В ВУ, СТС и охотничьем билете серия допускает буквы, но в шаблоне цифры, так как в современных бланках там цифры.

## Поведение маски

- Недопустимые символы не вводятся, пробелы и дефисы маска ставит сама.
- Строчные буквы становятся заглавными; при вставке отбрасывается мусор (`№`, точки, лишние пробелы).
- Там, где серия только из русских букв, латинские двойники заменяются на кириллицу (`ab` → `АВ`).
- На бэкенд уходит значение без пробелов и дефисов — в формате регулярок выше.

## Ошибки

| Ситуация | Когда показываем | Текст |
|---|---|---|
| Поле пустое | только по кнопке «Отправить» | `Укажите {документ}` |
| Номер не дописан / не проходит регулярку | после ухода из поля и по кнопке | `Проверьте {документ}` |
| Неверная римская часть серии (02, 13) | после ухода из поля и по кнопке | `Римская часть серии записана неверно` |
| Не сходится контрольное число СНИЛС | после ухода из поля и по кнопке | `Проверьте СНИЛС — не сходится контрольное число` |

Ввели и стёрли — не ругаемся. Вернулись в поле — ошибка скрывается.

Название документа в ошибке — с маленькой буквы, аббревиатуры как есть. Для женского рода задан падеж: «справку об освобождении…», «миграционную карту».

## Подключение

```html
<script src="doc-masks.js"></script>
<script>
  const mask = DocMasks.attachDocMask(input, '01', (state) => {
    // state: { display, value, valid, empty, error }
  });
  mask.setDoc('14'); // сменить тип документа

  input.addEventListener('blur', () => {
    const s = mask.getState();
    showError(!s.valid && !s.empty ? s.error : null);
  });
  submitButton.addEventListener('click', () => {
    const s = mask.getState();
    showError(s.valid ? null : s.error);
  });
</script>
```

## Замечания к регуляркам

- На бэкенде регулярки нужно обернуть в `^(?:...)$`, иначе `\d{10}` найдёт совпадение внутри более длинной строки.
- В регулярке 22 (ВУ) не хватает открывающей скобки, а вторая ветка покрывает первую: фактически принимается любая строка из 6–32 букв и цифр.
